# Data, screenshots, and third-party artifact policy

This repository preserves material for reproducibility. Before publishing it publicly:

- Review upstream licences for every public notebook, prompt, or ZIP retained under `research/bundles/` or `submissions/archive/`.
- The Budget-Fit reference is discussed in research reports with attribution; this repository's current prompt is independently authored and is not represented as a copy of that reference bundle.
- The public study reviewed for the October 23 configuration is licensed CC BY 4.0; link and attribution are included in the research report.
- Screenshots are cropped to show competition status or score evidence and can still contain account-specific context. Review them before a public push and remove any image you do not want public.
- Never store Kaggle tokens, `.env` values, session cookies, private hidden-task data, or private repository contents.
- Keep hidden-test patches and any private solutions out of this repository.
- A public score screenshot is not proof that a particular local ZIP generated the row unless the submission identifier or hash establishes the connection.
