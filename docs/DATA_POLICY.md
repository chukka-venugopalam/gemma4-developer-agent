# Data and Safety Policy

- Do not commit Kaggle API tokens, notebook secrets, `.env` files, private credentials, or browser cookies.
- Do not download/upload hidden evaluation tasks, hidden patches, or private repository contents into this repository.
- Public development-set materials should be added only if competition rules allow it, with provenance and licensing noted.
- Raw terminal output and screenshots are preserved as evidence; inspect for accidental secrets or personal information before making the repository public.
- Research summaries must distinguish verified, inferred, unknown, and blocked claims.
- Never label a custom static validator or synthetic fixture as an official harness run.
- Any score observation without archive linkage must be explicitly marked unattributed.
- No third-party notebook prompt/source is copied as an unexplained implementation dependency; references are linked in the research report.
