# Gemma 4 Developer Agent

Research and submission repository for the Google Gemma 4 Developer Agent Competition.

## Structure

- `submission/` — canonical source for the competition submission.
- `research/` — experiments and research artifacts; not submitted directly.
- `notebooks/` — Kaggle notebooks.
- `evaluation/` — evaluation configs, metrics, and results.
- `tools/` — validation and submission-building utilities.
- `docs/` — competition, harness, research, and decision documentation.

## Core rule

`submission/` must remain independently buildable into the competition `submission.zip`.

Do not manually maintain a second copy of submission files.
