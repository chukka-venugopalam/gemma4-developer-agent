# Official preflight notebook materials

This directory preserves the Prompt 6 preflight report, run order, and notebook pack from the earlier S0 attempt. The pack predates the October 23 Budget-Fit-Inspired V3 candidate; review and adapt the notebook to test the exact current `dist/submission.zip` before using it.

Required evidence to save after running in Kaggle:

1. Actual Python and wheelhouse package versions.
2. Official validator/compiler output and exit code.
3. Effective `eval_config.yaml` settings.
4. A one- or two-task real Gemma trace if compilation succeeds.
5. Full traceback for any `Notebook Threw Exception` status.
