# design_calculations.md

Raw outputs of `devset_tools.py power` and `devset_tools.py budget-arith`. These are **design calculations under stated assumptions and arithmetic from stated parameters**; they are not measurements of Gemma, the harness, or the dev set.

Reproduce with:
```
python devset_tools.py power --n 22,45,58 --seeds 1,3 --p0 0.10,0.20 --icc 0.3,0.6 --odds-ratio 1,2,3,5 --sims 1000 --seed 0 --out out/power_a
python devset_tools.py power --n 129      --seeds 1,3 --p0 0.10,0.20 --icc 0.3,0.6 --odds-ratio 1,2,3,5 --sims 1000 --seed 0 --out out/power_b
python devset_tools.py power --n 30,45,58 --seeds 1   --p0 0.40,0.60 --icc 0.3,0.6 --odds-ratio 1,2,3     --sims 1000 --seed 0 --out out/power_c   # mechanism-metric base rates
python devset_tools.py budget-arith --n-tasks 120,125 --out out/arith
```
