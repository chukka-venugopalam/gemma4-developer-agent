# Research Archive

- `reports/`: full report artifacts, preserving source content.
- `prompts/`: prompts used to request research and implementation work.
- `ablation/`: planned data/experiments and utilities; synthetic self-tests are not real Gemma evaluations.
- `bundles/`: original research output ZIPs preserved for provenance.
- `raw/`: raw terminal/search dumps, not polished conclusions.
- `notes/`: prior design reviews and explicitly unmeasured expected-impact estimates.
- `evidence/screenshots/`: visual evidence; not a ZIP-hash-to-score mapping.

Use evidence labels. Do not overwrite reports generated by earlier missions.
